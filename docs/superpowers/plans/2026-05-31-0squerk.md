# squerk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `0squerk`, a Rust CLI whose `decide` subcommand turns a GitHub `issue_comment` event + repo config into a merge `Decision`, plus the GitHub Action that rebuilds the squashed PR result, tests it, and squash-merges only on green.

**Architecture:** A pure Rust decision core (event parse + trigger + auth + config → `Decision{proceed, reason, command}`). All git/gh/network lives in the workflow, which rebuilds the squash result in an isolated runner, runs the command, and merges via `gh pr merge --squash` guarded by an unchanged-base check and serialized by `concurrency`.

**Tech Stack:** Rust (edition 2021), `clap`, `serde`/`serde_json`, `toml`. GitHub Actions + `gh` CLI. Cargo package/lib `squerk`, binary target `0squerk`.

```rust
use crate::auth;
use crate::config::{self, Config};
use crate::event::Event;
use crate::trigger;
use serde::Serialize;

#[derive(Serialize, Debug, PartialEq)]
pub struct Decision {
    pub proceed: bool,
    pub reason: String,
    pub command: String,
}

pub fn decide(event: &Event, cfg: &Config) -> Decision {
    let command = config::command(cfg);
    if event.issue.pull_request.is_none() {
        return Decision { proceed: false, reason: "not a pull request".into(), command };
    }
    if !trigger::is_merge(&event.comment.body) {
        return Decision { proceed: false, reason: "not a /merge command".into(), command };
    }
    if !auth::is_write(&event.comment.author_association) {
        return Decision { proceed: false, reason: "author lacks write access".into(), command };
    }
    Decision { proceed: true, reason: String::new(), command }
}
```

```rust
use clap::{Parser, Subcommand};
use squerk::{config, decide, event};
use std::fs;
use std::path::PathBuf;

#[derive(Parser)]
#[command(name = "0squerk")]
struct Cli {
    #[command(subcommand)]
    command: Command,
}

#[derive(Subcommand)]
enum Command {
    /// Decide whether a comment event should trigger a merge.
    Decide {
        #[arg(long)]
        event: PathBuf,
        #[arg(long)]
        config: PathBuf,
        #[arg(long)]
        out: PathBuf,
    },
}

fn main() {
    let cli = Cli::parse();
    match cli.command {
        Command::Decide { event: event_path, config: config_path, out } => {
            let ev = event::parse(&fs::read_to_string(&event_path).expect("read event.json"))
                .expect("parse event.json");
            // config file may be absent -> empty string -> default command
            let cfg = config::parse(&fs::read_to_string(&config_path).unwrap_or_default());
            let decision = decide::decide(&ev, &cfg);
            fs::write(&out, serde_json::to_string_pretty(&decision).unwrap())
                .expect("write decision.json");
        }
    }
}
```

## Task 8: Workflow

**Files:**
- Create: `action/0squerk.yml`

Orchestration glue (not Rust-unit-tested). Create it verbatim:

```yaml
name: 0squerk
on:
  issue_comment:
    types: [created]

concurrency:
  group: squerk-${{ github.repository }}
  cancel-in-progress: false

permissions:
  contents: read

jobs:
  merge:
    if: ${{ github.event.issue.pull_request && startsWith(github.event.comment.body, '/merge') }}
    runs-on: ubuntu-latest
    steps:
      - name: Mint app token
        id: app
        uses: actions/create-github-app-token@v1
        with:
          app-id: ${{ secrets.SQUERK_APP_ID }}
          private-key: ${{ secrets.SQUERK_APP_PRIVATE_KEY }}

      - name: Checkout default branch
        uses: actions/checkout@v4
        with:
          fetch-depth: 0
          token: ${{ steps.app.outputs.token }}

      - name: Install 0squerk
        run: cargo install --git https://github.com/0nybl/0squerk --tag v0.1.0 --bin 0squerk squerk

      - name: Write event payload
        env:
          EVENT: ${{ toJSON(github.event) }}
        run: printf '%s' "$EVENT" > event.json

      - name: Decide
        run: 0squerk decide --event event.json --config .0merge.toml --out decision.json

      - name: Gate
        id: gate
        env:
          GH_TOKEN: ${{ steps.app.outputs.token }}
          PR: ${{ github.event.issue.number }}
        run: |
          proceed="$(jq -r '.proceed' decision.json)"
          echo "proceed=$proceed" >> "$GITHUB_OUTPUT"
          if [ "$proceed" != "true" ]; then
            gh pr comment "$PR" --body "🚫 squerk: $(jq -r '.reason' decision.json)"
          fi

      - name: Acknowledge
        if: steps.gate.outputs.proceed == 'true'
        env:
          GH_TOKEN: ${{ steps.app.outputs.token }}
          PR: ${{ github.event.issue.number }}
        run: gh pr comment "$PR" --body "🛠 squerk is rebuilding and testing this PR…"

      - name: Rebuild squashed result and test
        if: steps.gate.outputs.proceed == 'true'
        id: build
        env:
          GH_TOKEN: ${{ steps.app.outputs.token }}
          PR: ${{ github.event.issue.number }}
        run: |
          B0="$(git rev-parse HEAD)"
          echo "b0=$B0" >> "$GITHUB_OUTPUT"
          git fetch origin "pull/$PR/head:squerk-pr"
          git merge --squash squerk-pr
          title="$(gh pr view "$PR" --json title --jq .title)"
          git -c user.name=0squerk -c user.email=bot@0nybl.dev commit -m "$title (#$PR)"
          cmd="$(jq -r '.command' decision.json)"
          set +e
          bash -lc "$cmd" 2>&1 | tee build.log
          echo "code=${PIPESTATUS[0]}" >> "$GITHUB_OUTPUT"

      - name: Report failure
        if: steps.gate.outputs.proceed == 'true' && steps.build.outputs.code != '0'
        env:
          GH_TOKEN: ${{ steps.app.outputs.token }}
          PR: ${{ github.event.issue.number }}
        run: |
          tail -c 4000 build.log > tail.log
          printf '❌ squerk: tests failed, not merging.\n\n```\n%s\n```\n' "$(cat tail.log)" \
            | gh pr comment "$PR" --body-file -
          exit 1

      - name: Guard base unchanged
        if: steps.gate.outputs.proceed == 'true' && steps.build.outputs.code == '0'
        id: guard
        run: |
          git fetch origin "${{ github.event.repository.default_branch }}"
          now="$(git rev-parse "origin/${{ github.event.repository.default_branch }}")"
          if [ "$now" != "${{ steps.build.outputs.b0 }}" ]; then
            echo "moved=1" >> "$GITHUB_OUTPUT"
          fi

      - name: Report base moved
        if: steps.gate.outputs.proceed == 'true' && steps.build.outputs.code == '0' && steps.guard.outputs.moved == '1'
        env:
          GH_TOKEN: ${{ steps.app.outputs.token }}
          PR: ${{ github.event.issue.number }}
        run: gh pr comment "$PR" --body "⏳ squerk: base moved during the build — re-run /merge."

      - name: Merge
        if: steps.gate.outputs.proceed == 'true' && steps.build.outputs.code == '0' && steps.guard.outputs.moved != '1'
        env:
          GH_TOKEN: ${{ steps.app.outputs.token }}
          PR: ${{ github.event.issue.number }}
        run: |
          gh pr merge "$PR" --squash --delete-branch
          gh pr comment "$PR" --body "✅ merged by squerk"
```

```markdown
# 0squerk

Comment-driven merge bot for the `0nybl` fleet. Comment `/merge` on a pull
request and squerk rebuilds the squashed result in an isolated runner, runs the
tests, and squash-merges only if they pass — so the default branch stays green.

## Use

Comment `/merge` on a PR (you need write access). squerk will:
1. rebuild the squash of your PR onto the default branch,
2. run the test command (`.0merge.toml` `command`, default `cargo test --all`),
3. squash-merge if green, or comment the failure if not.

Merges are serialized, so concurrent `/merge`s can't race the base branch.

## Config (`.0merge.toml`, optional)

    command = "cargo test --all"

## CLI

    0squerk decide --event event.json --config .0merge.toml --out decision.json

`decide` is pure (no network): it turns the comment event + config into
`{proceed, reason, command}`. All git/merge actions live in `action/0squerk.yml`.
Merges are attributed to the `0squerk[bot]` GitHub App.

Cargo package/lib `squerk`; binary `0squerk`.
```
